# Documentación del Proyecto: Header Crocs Colombia

## Resumen
Este proyecto implementa un header (encabezado) responsivo inspirado en el sitio crocs.com.co, incluyendo una franja superior (top header) y un menú de navegación principal, siguiendo el diseño y experiencia de usuario de la tienda oficial.

## Estructura de Archivos
- `header-ejemplo.html`: Archivo HTML principal que contiene la estructura del header y top header.
- `header-ejemplo.css`: Archivo CSS externo con todos los estilos del header y top header.
- `Funcionalidades - Hoja 1.csv`: Archivo CSV de referencia, no modificado.

## Funcionalidades Implementadas
- **Top Header:**
  - Franja superior con mensaje de beneficio ("Envío gratis en compras superiores a $150.000").
  - Enlaces rápidos a la derecha: Ayuda, Club Crocs, Encuentra tu tienda.
- **Header Principal:**
  - Logo oficial de Crocs Colombia.
  - Menú de navegación con las secciones: Mujer, Hombre, Niños, Jibbitz™ Charms, Crocs at Work™, Rebajas (con imagen de oferta).
  - Barra de búsqueda con ícono de lupa.
  - Íconos de favoritos (corazón) y carrito de compras (SVG).
- **Estilos:**
  - Todo el CSS está en `header-ejemplo.css`.
  - Se utiliza la fuente Montserrat por defecto, con opción de cambiar a 'TT Crocs' si se dispone del archivo de fuente.
- **Accesibilidad y UX:**
  - Navegación clara, botones accesibles, y diseño responsivo.

## Flujo de Trabajo y Commits
- Se crearon y refactorizaron los archivos HTML y CSS para separar la lógica de estilos.
- Se realizaron commits descriptivos y se preparó una rama para Pull Request (`feature/header-font-agent`).
- Se documentó el proceso para subir ramas y crear PR en GitHub.

## Pendientes y Notas
- Si se dispone del archivo de fuente 'TT Crocs', se puede integrar fácilmente en el CSS.
- El header es fácilmente personalizable para otros beneficios, enlaces o estilos.
